Ruler

Measure anything on your screen.

Download for macOS

Free · Universal · macOS 13 or later

Install

  1. Open Ruler.dmg and drag Ruler into your Applications folder.
  2. Ruler isn’t signed with an Apple Developer ID, so the first launch is blocked. Open System Settings → Privacy & Security and click Open Anyway — or run this once:
    xattr -dr com.apple.quarantine /Applications/Ruler.app
  3. Look for the ruler in your menu bar. There’s no Dock icon.

Prefer Homebrew?

brew install --cask simpel/tap/ruler

What it does

Live readout

Both rulers track the pointer in pixels, over any app.

Drag to measure

Shift-drag anywhere for distance, width and height.

Crosshair

Screen-wide marklines that follow the cursor.

Guides

Pull fixed lines off a ruler and drag them where you want.

Points or pixels

Logical points, or physical Retina pixels.

No permissions

No accessibility or screen-recording access needed.
