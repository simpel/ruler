Ruler

Measure anything on your screen.

Free · Universal · macOS 13 or later

Install — two steps

1

Install it

Paste this in Terminal.

brew install --cask simpel/tap/ruler

No Homebrew yet? Get it at brew.sh.

2

Let macOS open it

Ruler isn’t signed with an Apple Developer ID, so the first launch is blocked. Run this once — or open System Settings → Privacy & Security and click Open Anyway.

xattr -dr com.apple.quarantine /Applications/Ruler.app

That’s it — Ruler appears in your menu bar. There’s no Dock icon.

What it does

Live readout

Both rulers track the pointer in pixels, over any app.

Drag to measure

Shift-drag anywhere. Measurements stay until you dismiss them.

Crosshair

Screen-wide marklines that follow the cursor.

Guides

Pull fixed lines off a ruler and drag them where you want.

Points or pixels

Logical points, or physical Retina pixels.

No permissions

No accessibility or screen-recording access needed.
